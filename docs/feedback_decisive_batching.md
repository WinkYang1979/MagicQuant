用户明确表达过(2026-05-22):**"把你觉得要写的一次性写好,不要写一点问我要不要加新的。"**

含义:
- 我判断该做的(写文档/规格/memory/分析),**当轮一次性做完**,别拆成"先做一半 + 结尾问要不要继续"。
- 少用"要不要我接着…?"这类收尾提问。真有该做的就直接做;真有需要他拍板的**决策点**(方案二选一、会改线上行为)才问,而且一次问清。
- 他给的是方向,执行细节和配套产出(顺带的 memory、索引、相关规格)我自己补齐,不用逐项请示。

边界:这是"执行/产出"层面的主动;**改策略代码、动线上行为**仍要先讨论(那是另一条纪律,见 feedback_silence_vs_spam / patient_iteration)。
