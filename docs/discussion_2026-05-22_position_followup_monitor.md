# PositionFollowupMonitor 持仓看护方案讨论稿

日期: 2026-05-22  
状态: 讨论稿, 暂不改主策略  
范围: 持仓后的方向看护、波顶提示、方向失效提示  

## 1. 背景

当前系统主策略负责发现方向信号, 但用户实际交易中还有一个更痛的环节:

- 入场后不知道方向是否仍然成立
- 止盈/止损价曾经给得太近, 容易影响心态
- 5m K 线用于主方向较稳, 但持仓后的波顶/失效提示可能不够及时
- 用户希望方向判断优先, 到了波顶及时提示卖出, 即使不能吃满收益也可以接受

因此建议新增一个独立的持仓看护模块:

`PositionFollowupMonitor`

它不替代主方向策略, 只在已经有持仓时工作。

## 2. 核心目标

持仓模块只回答四个问题:

1. 当前持仓方向还成立吗?
2. 是否接近波顶?
3. 是否已经进入适合锁定利润的区域?
4. 原来的入场方向是否已经失效?

它不负责:

- 判断是否新开仓
- 计算买多少
- 频繁提示固定止盈价
- 反复催促卖出

## 3. 数据分工

### 3.1 5m K 线

5m 用于判断主结构, 负责“方向是否还成立”:

- 价格是否仍在 VWAP 上方或下方
- 5m 高低点结构是否仍然顺势
- 是否跌破/突破关键支撑压力
- RSI 是否进入极端区
- 是否出现 5m 级别放量反转

5m 是主判断, 避免 1m 噪音导致频繁误判。

### 3.2 1m K 线

1m 用于及时确认, 负责“波顶/失效是否正在发生”:

- 连续 2-3 根 1m 高点不再创新高
- 1m 跌破 MA5/MA10
- 1m 放量长上影
- 1m 跌破短线 VWAP 或跌破后反抽不过
- 从局部高点回撤超过 1m ATR 或固定最小阈值

1m 不单独决定大方向, 只作为持仓后的提前预警。

## 4. 状态机设计

建议持仓后维护四个状态。

### 4.1 HOLD_OK

含义: 持仓方向仍然成立。

典型条件:

- 做多时 RKLB 仍在 5m VWAP 上方或关键结构未破
- 5m 没有明显 lower-high / lower-low
- follower 与 RKLB 方向一致
- 没有明显放量反向 K 线

推送策略:

- 不频繁单独推送
- 只在心跳或状态变化时展示

示例文案:

```text
持仓方向仍成立
RKLB 仍在 VWAP 上方, 5m 结构未破
参考失效位: $XX
```

### 4.2 TOP_WATCH

含义: 接近波顶, 需要开始观察卖出窗口。

典型条件:

- RSI > 72
- 价格明显偏离 VWAP
- RKLX/RKLB 短时间快速拉升
- 1m 出现上影或动能减弱
- 1m 高点开始不再继续抬高

推送策略:

- 每个波段最多 1 次
- 不直接要求卖出, 只提示进入观察区

示例文案:

```text
波顶观察
上涨动能开始放缓, 已有回落风险
可考虑分批锁定利润
关键守住: $XX
```

### 4.3 TAKE_PROFIT_ZONE

含义: 波顶初步确认, 适合考虑锁定部分利润。

典型条件:

- 从局部高点回撤超过 1m ATR 或 0.8%-1.2%
- 1m 连续 lower high
- 跌破 1m MA10 后反抽不过
- RSI 从高位明显回落
- 量能转弱

推送策略:

- 每 10-15 分钟最多 1 次
- 只在状态从 TOP_WATCH 升级时立即推
- 避免盈利刚开始就提示止盈

示例文案:

```text
波顶确认
短线结构转弱, 建议先锁定部分利润
若跌破 $XX, 剩余仓位风险加大
```

### 4.4 INVALIDATED

含义: 原入场方向失效。

典型条件:

- 做多后 RKLB 跌破 5m VWAP 且收不回
- 5m 关键支撑跌破
- RKLX 跌破真实 ATR 失效位
- RKLB 与 RKLX 同时走弱
- 主方向信号被反向结构否定

推送策略:

- 可以立即推送
- 同一 ticker / 同一方向 5-10 分钟冷却
- 文案必须清楚说明失效依据

示例文案:

```text
方向失效
做多假设被破坏, 建议减仓/退出
失效依据: 跌破 VWAP + 5m 结构转弱
```

## 5. 价格逻辑

持仓模块不应再以“固定目标价到了就卖”为核心。

建议改成:

- 入场后记录结构失效位
- 盈利后动态上移保护位
- 接近波顶时提示减仓窗口
- 明确转弱时提示方向失效

也就是:

```text
方向还在不催卖
接近波顶才提醒
结构失效才明确提示退出
```

## 6. 推送频率

为了避免干扰交易心态:

- HOLD_OK: 不频繁推送, 只进心跳
- TOP_WATCH: 每个波段最多 1 次
- TAKE_PROFIT_ZONE: 每 10-15 分钟最多 1 次
- INVALIDATED: 立即推, 但 5-10 分钟冷却
- 状态未变化不推

## 7. 第一版落地范围

建议第一版保持小而稳:

1. 新增 `PositionFollowupMonitor`
2. 只在已有持仓时工作
3. 只服务 RKLB / RKLX / RKLZ
4. 5m 判断主结构, 1m 只做及时确认
5. 只输出三类主动推送:
   - 波顶观察
   - 波顶确认
   - 方向失效

不改:

- `check_direction_trend`
- `check_intraday_reversal`
- `run_all_triggers` 主策略 dispatch
- 主方向置信度逻辑

## 9. 待讨论问题

1. 1m K 线是实时循环获取, 还是只在已有持仓后启用?
2. 1m 数据获取频率设为多少合适?
   - 30 秒?
   - 60 秒?
   - 只在高波动/持仓时启用?
3. TOP_WATCH 是否需要 Telegram 单独推送, 还是只进入心跳?
4. TAKE_PROFIT_ZONE 是否应该带建议比例, 还是只说“可考虑锁定部分利润”?
5. INVALIDATED 是否要生成一键卖出按钮?

## 10. 当前倾向

我的倾向:

- 持仓后才启用 1m K 线
- 1m 用于确认, 不用于主方向
- 不再用很近的固定止盈价影响判断
- 优先提示方向是否成立
- 波顶确认后再提示锁定利润
- 方向失效时才给明确退出建议

一句话:

```text
主策略负责发现机会, PositionFollowupMonitor 负责持仓后的“拿住、减仓、退出”。
```
