# SimWeekly — 周度模拟盘(自主·收益最大化版) 设计方案

日期: 2026-05-22 · 状态: 设计稿 · 性质: 纯纸面模拟,绝不碰实盘/主策略

## 0. 目标(已按用户最新指示重定)
**放手让 Claude 用 $10,000 全自主操作,目标:一周(周一开盘→周五收盘)收益最大化。**
- **不迁就用户的保守风格**——该上杠杆上杠杆、该做空(用反向 ETF)就做、该重仓就重仓、该频繁交易就频繁。
- **调用一切可用资源**:杠杆工具、双向暴露、LLM agent(可多模型)、完整信号流与指标、历史数据。
- 唯一的硬约束是**别把账户打爆**(见 §4.5 防爆仓)——因为爆仓 = 收益归零,不是"最大化"。
- 全自动、可审计、纯纸面。

> 诚实前提:**一周是极短窗口,方差主导**。单笔集中杠杆赌对/赌错就能决定整周结果。所以目标精确说是"**在不被单次爆掉的前提下,最大化期望收益**",这张周记分卡更像一次"放手实验",不是策略定论。

## 1. 复用 vs 新增
复用现网 AI-race 执行层:`VirtualPortfolio`、`calc_moomoo_au_fee`(真手续费)、`providers`(多模型 LLM)、`parse_decision`、行情/指标取数、market_clock。
新增:`core/agents/sim_weekly.py` —— 独立 loop + 自主决策引擎 + 周期管理 + 记分卡。独立状态,不进 race、不动 `portfolio_*.json`。

## 2. 标的与方向(放开)
- **全家族都用**:RKLB(1x)、RKLX(≈2x 多)、RKLZ(≈2x 空/反向)。
- **双向**:看多→买 RKLB/RKLX(高信念用 RKLX 加杠杆);看空→买 RKLZ(等于做空 RKLB,无需融券机制)。
- **按信念选工具**:信念越强越用杠杆 ETF;信念中等用 RKLB。

## 3. 架构
- 独立线程 loop;**风险检查每轮(随 focus poll,秒级),决策评估更积极(30–60s)**——追求收益要反应快。
- 数据复用 focus 已算的 quotes / 5m 指标 / `market_snapshot.json` / 信号事件,不另开订阅(避免又一条会冻结的流)。
- 状态:`data/sim_weekly/portfolio.json` + 周归档 `week_<YYYY-WW>.json`。

## 4. 决策引擎(自主·进取)
### 4.1 Alpha 来源:agent 委员会 + 信号流
- **主动调用多模型 agent**(复用 providers:Claude/GPT/DeepSeek/Kimi),做成**委员会**:每个决策点喂 {market_snapshot + 持仓 + 5m 结构/RSI/VWAP/ATR + focus 当前信号},各自给 `{direction, conviction 0-100, instrument, reason}`。
- 聚合:方向**多数票**,`conviction = 同向模型的加权均值`;分歧大→降信念或空仓。
- 同时把 focus 的 STRONG 信号作为**加分项**(信号与委员会同向 → 提高信念/仓位)。
- 调用频率比保守版高(进取),但仍**事件优先**(信号事件、持仓异动、整 30–60s 一次),记录每次 tokens/cost,周末汇总 AI 成本并计入净收益考量。

### 4.2 仓位:信念驱动、敢重仓、可加仓
- 按信念分档放大风险预算(不再是固定 1.5%):
  - conviction ≥85:可投入到 **60–80% 权益**(高信念用 RKLX 即等效 1.2–1.6x 总杠杆)。
  - 70–85:30–50%。
  - <70:0–20% 或空仓。
- **金字塔加仓**:浮盈且信念维持 → 用部分浮盈加仓,放大趋势收益。
- 现金不上真杠杆(不融资),杠杆完全通过 RKLX/RKLZ 实现。

### 4.3 退出:让赢家跑、输家快砍
- **输家**:ATR 硬止损,跌破即砍(秒级,不问 agent)——保住子弹打下一发。
- **赢家**:**不做"1×ATR 减半"那种保守落袋**;用**跟踪止损**(盈利后上移 ATR 跟踪线)尽量吃满趋势。只有委员会明确转向 / 5m 结构破位才主动了结。
- 可日内反手(平多→开空 via RKLZ),只要委员会方向翻转且过滤确认。

### 4.4 成交真实度
复用 `VirtualPortfolio.buy/sell` + `calc_moomoo_au_fee`,加滑点(0.05–0.1%),频繁交易/杠杆 ETF 的点差成本也要体现——否则"最大化"是假的。无 PDT(Moomoo AU)。

### 4.5 防爆仓(唯一硬护栏)
- 单一持仓的**最大可承受亏损 ≤ 权益的 15%**(止损距离 × 仓位反推上限)。
- 总杠杆暴露(按 ETF 等效)**≤ ~2.5x**。
- 任一时刻保留 ≥ 10% 现金(留加仓/反手余地)。
- 触发周内累计回撤 -35% → 自动降挡(减半仓位预算),防止一周内自杀式归零。

## 5. 周期与结算
- 周一 09:30 ET reset 到 $10k(归档上周)。
- 周中可隔夜/可反手。
- 周五 16:00 ET 全平结算,出本周记分卡。

## 6. 周度记分卡(周五推送 + 落盘)
- **周收益 %**、期末权益、最大回撤、夏普/单周波动、交易笔数、胜率、平均盈亏比、总手续费+滑点、AI 成本、平均/最高杠杆暴露、最大单仓占比。
- **基准对照**:同期 **buy&hold RKLB** 与 **buy&hold RKLX(2x)** 的收益% —— 看主动+杠杆到底有没有跑赢"无脑拿"。
- 全交易清单(入场:委员会票型/信念/工具/理由;出场:原因)。

## 7. 命令 & 推送
`/sim_status`(实时权益/持仓/杠杆)、`/sim_week`(记分卡)。入场/平仓/反手各推简短回执;周五自动推记分卡。

## 8. 独立性与安全(硬约束,不因"激进"放松)
- **纯纸面,永不下真单**;独立状态文件,不碰 race / 实盘 / 主策略(`check_*`/dispatch/置信度/ATR 只读消费)。
- sim loop 崩溃**不得**影响 focus 盯盘主循环(独立线程 + try/except)。
- 所有推送/记录显著标注"模拟盘"。

## 9. 验收 / 回放
- 先**离线回放**最近几周(含 05-19~05-22),喂同一决策引擎跑:
  1. P&L(手续费+滑点+隔夜+杠杆 ETF 路径)算对、无崩;
  2. 周收益 vs buy&hold RKLB / RKLX 对照合理;
  3. 防爆仓护栏生效(构造一个暴跌隔夜,确认不会 -80%);
  4. agent 委员会成本在预算内。
- 回放通过再实时跑下周一整周。
- `tests/test_sim_weekly.py`:reset / 多空买卖 / 手续费滑点 / 加仓 / 反手 / 止损 / 回撤降挡 / 周五结算 / 记分卡。`PYTHONIOENCODING=utf-8`。

## 10. 我的关键自主决定(已按"收益最大化"定)
| 项 | 决定 |
|---|---|
| 标的 | RKLB + RKLX + RKLZ 全用 |
| 方向 | 双向(RKLZ 表达空头) |
| 杠杆 | 通过 2x ETF,等效总暴露 ≤ 2.5x |
| 仓位 | 信念驱动,高信念可 60–80% 权益,允许金字塔加仓 |
| 赢家 | 跟踪止损吃趋势,不提前保守落袋 |
| Alpha | 多模型 agent 委员会 + focus 信号加分 |
| 护栏 | 单仓最大亏损 ≤15% 权益;周回撤 -35% 降挡 |

## 11. 落地顺序
1. `sim_weekly.py` 骨架:VirtualPortfolio + 周期 + 记分卡 + 防爆仓护栏(先**规则版**,委员会用单模型或纯信号占位)。
2. 离线回放验收(含爆仓压力测试)。
3. 接多模型 agent 委员会。
4. 命令 + 周五自动推送。
5. 实时跑一整周,出第一张记分卡。

> 一句话:**放手——$10k、全家族双向、2x ETF 加杠杆、多模型 agent 委员会定方向、信念重仓 + 跟踪止损吃趋势、唯一红线是别被单发打爆,周五出"主动 vs 躺平 RKLB/RKLX"的收益记分卡。** 纯纸面,不碰实盘与主策略。
